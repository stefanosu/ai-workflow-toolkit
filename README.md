# AI Workflow Toolkit

A personal reference library for AI-assisted development, system design, and algorithmic thinking.

---

## Purpose

This repo serves as my reusable toolkit for:
- **AI-assisted coding workflows** - Regimented processes for efficient development
- **Prompt patterns** - Battle-tested prompts organized by use case
- **System design frameworks** - High-level architecture templates
- **Algorithm practice** - Patterns and mental models for problem-solving

## Philosophy

> AI is a force multiplier, not a replacement for understanding.

The goal is to move faster while maintaining ownership. Every line of code I ship, I can explain, debug, and modify.

## Quick Start

### Starting a New Project
1. Review `templates/PROJECT_KICKOFF.md` checklist
2. Define requirements and constraints upfront
3. Follow `processes/WORKFLOW.md` stages
4. Use prompts from `prompts/PROMPT_LIBRARY.md`

### Tackling System Design
1. Use `system-design/FRAMEWORK.md` to structure thinking
2. Reference templates for common architectures
3. Document decisions and trade-offs

### Practicing Algorithms
1. Study patterns in `algorithms/PATTERNS.md`
2. Apply mental models from `algorithms/MENTAL_MODELS.md`
3. Explain solutions out loud (teaching test)

---

## Core Principles

1. **Incremental over monolithic** - Small chunks, early verification
2. **Specification before implementation** - Clear requirements prevent rewrites
3. **Constraints are features** - Explicit limits prevent over-engineering
4. **Read before write** - Understand before modifying
5. **Verify, don't trust** - Test everything AI generates
6. **Own everything** - If you can't explain it, you don't ship it
